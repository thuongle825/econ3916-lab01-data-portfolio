# The Data Portfolio — Big Mac Index Analysis

**Objective:** This project applies purchasing power parity theory to The Economist's Big Mac Index dataset to evaluate currency misalignment across 57 countries and identify systematic patterns in exchange rate deviations over a 22-year period.

**Methodology:**
- Sourced and loaded panel data (57 countries, 45 periods, Jan 2000–Jul 2026) from The Economist's public GitHub repository
- Computed implied PPP exchange rates and percentage over/undervaluation relative to actual market rates
- Classified the dataset's structural dimensions (cross-sectional, time series, and panel views)
- Diagnosed missingness mechanisms, including classification of Russia's series exit as Missing Not At Random (MNAR)
- Built visualizations: a horizontal bar chart of cross-sectional valuation distribution and a time series comparison of currency valuation trends

**Key Findings:**
- The Swiss franc showed persistent overvaluation, reaching +41.8% in the July 2024 cross-section
- The Japanese yen remained undervalued on average across every decade in the sample, suggesting a structural rather than transient deviation
- Results are consistent with the Balassa-Samuelson effect, where non-tradeable input costs (labor, rent) drive durable PPP gaps that a simple burger-price comparison can't arbitrage away
